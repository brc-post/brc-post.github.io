        How signing works
        

          
Your BrowserCoin address is a public key. Your wallet's private key can make a signature: a 128-character code that only that key can produce, and that fits only this exact message.

          
    
            
  1. The page signs your message together with your address and a fixed label, BrowserCoin Signed Message v1.
    2. 
            
  2. Anyone who pastes the block into BRC Seal → I received something can check the signature against the address. No wallet needed.
    3. 
            
  3. Change one letter of the message and the check fails.
    4. 
          

          
It can't move your coins. Coin transfers sign a completely different layout of bytes, which starts with BrowserCoin's chain number. A message signature can never be used as a payment.

          
Uses: claiming a Discord role as a real miner, entering the block 100,000 giveaway, proving a pool payout address is yours, settling "that's my address" arguments.

        How sealing works, and its one limit
        

          
Because a BrowserCoin address is a public key, it can be turned into an encryption key. Anyone can lock a letter with it. Only the matching wallet can unlock it.

          
    
            
  1. The page makes a one-time key just for this letter and combines it with the recipient's address (X25519).
    2. 
            
  2. The letter is encrypted with XChaCha20-Poly1305, the same kind of encryption modern messengers use. Any change to the sealed text makes it refuse to open.
    3. 
            
  3. If you tick "sign it", your signature goes inside the encryption, so outsiders can't see it was you. The recipient can, and could later show others that you wrote it. Otherwise the letter is anonymous.
    4. 
            
  4. Signed and anonymous letters are the same size, and the length is rounded up in 64-byte steps, so the size gives little away.
    5. 
          

          
The limit: there are no rotating keys. If the recipient's wallet key is ever stolen, every letter ever sealed to that address can be read. That's fine for one-off letters, not for an ongoing private conversation. That's what BRC Post would add.

          
Visible to everyone: who the letter is for (the "To:" line) and roughly how long it is. Not visible: what it says, who sent it, or whether it was signed.

        What a postmark proves, what it costs, and getting your coins back
        

          
Proves: this exact file existed no later than the block the lock landed in. The file may be older. Change one byte and it no longer matches. If you added a drand beacon, it also proves the postmark was made after that moment, to within 3 seconds; drand is run by the League of Entropy, a group of independent organisations. If you added a recent block, it proves the postmark was made after that block. The lock is signed by your wallet, so it shows which address posted it. Miners set block times: usually accurate to a few minutes, guaranteed within about half an hour.

          
Doesn't prove: who wrote the file, or what it means. It is not a notarization.

          
Private: only a fingerprint mixed with a random salt goes on-chain. Nobody can work out the file, or test guesses about it, without your receipt.

          
Cost: the app's default fee (0.00001 BRC), plus the small amount you lock. The lock is how the fingerprint gets on-chain, using BrowserCoin's built-in scripts. No fork, nothing new.

          
Getting the coins back: in the app, Scripts → Redeem a hash-locked payment, with the Lock ID and the same postmark phrase. The postmark stays valid after you redeem, because the lock stays in the chain's history. Redeeming reveals only a scrambled form of the phrase, so the fingerprint and salt stay private.

          
Keep the receipt. Without it, the postmark can't be found or proven. Keep it next to the file, or email it to yourself.

        What a valid signature does and doesn't prove
        

          
A valid result proves that whoever controls this address signed exactly this message.

          
    
            
  • It doesn't prove who that person is. Compare the address with one you already trust, for example from BRC Pulse or a past payment.
    • 
            
  • BrowserCoin addresses have no built-in typo check, so compare the whole address, not just the first few characters.
    • 
            
  • Someone can copy and repost your signed message. Put a date or a purpose in it, so an old one can't be passed off as new.

        Staying safe with letters
        

          
    
            
  • An anonymous letter could be from anyone. Treat its claims the way you'd treat an unsigned letter in the post.
    • 
            
  • A signed letter shows the sender's address, checked. It still only proves the address, not the person.
    • 
            
  • Never send your wallet file, private key or recovery words to anyone, however a letter asks. Nobody legitimate needs them.
