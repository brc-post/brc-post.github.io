          How signing works
          

            
Your BrowserCoin address is a public key. Your wallet's private key can make a signature: a 128-character code that only that key can produce, and that fits only this exact message.

            
    
              
  1. The page signs your message together with your address and a fixed label, BrowserCoin Signed Message v1.
    2. 
              
  2. Anyone who pastes the block into Verify can check the signature against the address. No wallet needed.
    3. 
              
  3. Change one letter of the message and the check fails.
    4. 
            

            
It can't move your coins. Coin transfers sign a completely different layout of bytes, which starts with BrowserCoin's chain number. A message signature can never be used as a payment.

            
Uses: claiming a Discord role as a real miner, entering the block 100,000 raffle, proving a pool payout address is yours, settling "that's my address" arguments.

          What a valid signature does and doesn't prove
          

            
A valid result proves that whoever controls this address signed exactly this message.

            
    
              
  • It doesn't prove who that person is. Compare the address with one you already trust, for example from BRC Pulse or a past payment.
    • 
              
  • BrowserCoin addresses have no built-in typo check, so compare the whole address, not just the first few characters.
    • 
              
  • Someone can copy and repost your signed message. Put a date or a purpose in it, so an old one can't be passed off as new.
    •

          How sealing works, and its one limit
          

            
Because a BrowserCoin address is a public key, it can be turned into an encryption key. Anyone can lock a note with it. Only the matching wallet can unlock it.

            
    
              
  1. The page makes a one-time key just for this note and combines it with the recipient's address (X25519).
    2. 
              
  2. The note is encrypted with XChaCha20-Poly1305, the same kind of encryption modern messengers use. Any change to the sealed text makes it refuse to open.
    3. 
              
  3. If you tick "sign it", your signature goes inside the encryption, so outsiders can't see it was you. The recipient can, and could later show others that you wrote it. Otherwise the note is anonymous.
    4. 
              
  4. Signed and anonymous notes are the same size, and the length is rounded up in 64-byte steps, so the size gives little away.
    5. 
            

            
The limit: there are no rotating keys. If the recipient's wallet key is ever stolen, every note ever sealed to that address can be read. That's fine for one-off notes, not for an ongoing private conversation. That's what BRC Post would add.

            
Visible to everyone: who the note is for (the "To:" line) and roughly how long it is. Not visible: what it says, who sent it, or whether it was signed.

          Staying safe with notes
          

            
    
              
  • An anonymous note could be from anyone. Treat its claims the way you'd treat an unsigned letter.
    • 
              
  • A signed note shows the sender's address, checked. It still only proves the address, not the person.
    • 
              
  • Never send your wallet file, private key or recovery words to anyone, however a note asks. Nobody legitimate needs them.
